</p>🌟 About The Project

Electricity Bill Management System is a console-based application developed using C programming. It calculates electricity bills based on customer details and units consumed.

The system provides automatic bill calculation, GST, late payment penalty, early payment discount, UPI payment simulation and digital receipt generation.

✨ Features

- 👤 Customer Details
- ⚡ Automatic Electricity Bill Calculation
- 🧾 GST Calculation
- ⏰ Late Payment Penalty
- 🎁 Early Payment Discount
- 💳 UPI Payment Simulation
- 📱 QR Code Representation
- 🔐 Transaction ID Generation
- 📄 Digital Receipt Generation
- 📩 Payment Confirmation Message

🛠️ Technologies Used

- C Programming
- Structures
- Functions
- Pointers
- File Handling

🚀 How To Run

1. Clone this repository.
2. Open the project folder.
3. Compile the C program using GCC.

gcc electricity_bill.c -o electricity_bill

4. Run the program:

./electricity_bill
